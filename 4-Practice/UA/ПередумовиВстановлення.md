## 1. kubectl — CLI Kubernetes

kubectl — це інструмент командного рядка для взаємодії з кластерами Kubernetes.

### macOS

**За допомогою Homebrew (рекомендовано):**
```bash
brew install kubectl
```

**За допомогою curl:**
```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/darwin/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/
```

Для Apple Silicon (M1/M2/M3):
```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/darwin/arm64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/
```

### Linux

**За допомогою curl:**
```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
chmod +x kubectl
sudo mv kubectl /usr/local/bin/
```

**За допомогою пакетного менеджера (Debian/Ubuntu):**
```bash
sudo apt-get update
sudo apt-get install -y apt-transport-https ca-certificates curl gnupg
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.31/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.31/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list
sudo apt-get update
sudo apt-get install -y kubectl
```

**За допомогою пакетного менеджера (RHEL/CentOS/Fedora):**
```bash
cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io/core:/stable:/v1.31/rpm/
enabled=1
gpgcheck=1
gpgkey=https://pkgs.k8s.io/core:/stable:/v1.31/rpm/repodata/repomd.xml.key
EOF
sudo yum install -y kubectl
```

### Windows

**За допомогою Chocolatey:**
```powershell
choco install kubernetes-cli
```

**За допомогою winget:**
```powershell
winget install -e --id Kubernetes.kubectl
```

**Завантаження вручну:**
1. Завантажте останній реліз за посиланням: https://dl.k8s.io/release/v1.31.0/bin/windows/amd64/kubectl.exe
2. Створіть папку `C:\kubectl` та перемістіть туди `kubectl.exe`
3. Додайте `C:\kubectl` до системної змінної середовища PATH

### Перевірка встановлення kubectl (усі платформи)

```bash
kubectl version --client
```

Очікуваний вивід:
```
Client Version: v1.31.x
Kustomize Version: v5.x.x
```

## 2. Кластер Kubernetes

У вас є два рекомендовані варіанти для запуску локального кластера Kubernetes: **minikube** або **kind**. Оберіть один.

### Варіант А: minikube

minikube запускає однонодовий кластер Kubernetes на вашій локальній машині.

#### Передумови для minikube

minikube потребує драйвер контейнера або віртуальної машини. Рекомендований драйвер залежить від платформи:
- **macOS**: Docker Desktop або HyperKit
- **Linux**: Docker
- **Windows**: Docker Desktop або Hyper-V

#### macOS

**За допомогою Homebrew:**
```bash
brew install minikube
```

**За допомогою curl:**
```bash
# Intel Mac
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-darwin-amd64
sudo install minikube-darwin-amd64 /usr/local/bin/minikube

# Apple Silicon (M1/M2/M3)
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-darwin-arm64
sudo install minikube-darwin-arm64 /usr/local/bin/minikube
```

#### Linux

**За допомогою curl:**
```bash
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube
```

**За допомогою пакетного менеджера (Debian/Ubuntu):**
```bash
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube_latest_amd64.deb
sudo dpkg -i minikube_latest_amd64.deb
```

**За допомогою пакетного менеджера (RHEL/CentOS/Fedora):**
```bash
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-latest.x86_64.rpm
sudo rpm -Uvh minikube-latest.x86_64.rpm
```

#### Windows

**За допомогою Chocolatey:**
```powershell
choco install minikube
```

**За допомогою winget:**
```powershell
winget install -e --id Kubernetes.minikube
```

**Завантаження вручну:**
1. Завантажте інсталятор за посиланням: https://storage.googleapis.com/minikube/releases/latest/minikube-installer.exe
2. Запустіть інсталятор

#### Запуск minikube (усі платформи)

```bash
# Запуск з драйвером за замовчуванням (автовизначення)
minikube start

# Або вказати драйвер явно
minikube start --driver=docker

# Для лабораторної роботи виділіть більше ресурсів
minikube start --cpus=4 --memory=8192
```

#### Перевірка встановлення minikube

```bash
minikube status
kubectl get nodes
```

Очікуваний вивід:
```
NAME       STATUS   ROLES           AGE   VERSION
minikube   Ready    control-plane   1m    v1.31.x
```

### Варіант Б: kind (Kubernetes in Docker)

kind запускає кластери Kubernetes, використовуючи контейнери Docker як вузли. Він легковаговий та швидкий.

#### Передумови для kind

kind потребує встановлений та запущений **Docker**.

#### macOS

**За допомогою Homebrew:**
```bash
brew install kind
```

**За допомогою Go:**
```bash
go install sigs.k8s.io/kind@latest
```

#### Linux

**За допомогою curl:**
```bash
# Для AMD64 / x86_64
[ $(uname -m) = x86_64 ] && curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.24.0/kind-linux-amd64

# Для ARM64
[ $(uname -m) = aarch64 ] && curl -Lo ./kind https://kind.sigs.k8s.io/dl/v0.24.0/kind-linux-arm64

chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind
```

**За допомогою Go:**
```bash
go install sigs.k8s.io/kind@latest
```

#### Windows

**За допомогою Chocolatey:**
```powershell
choco install kind
```

**За допомогою curl (PowerShell):**
```powershell
curl.exe -Lo kind-windows-amd64.exe https://kind.sigs.k8s.io/dl/v0.24.0/kind-windows-amd64
Move-Item .\kind-windows-amd64.exe C:\kind\kind.exe
# Додайте C:\kind до PATH
```

#### Створення кластера kind (усі платформи)

```bash
# Створити базовий кластер
kind create cluster --name argocd-lab

# Перевірити, що кластер працює
kubectl cluster-info --context kind-argocd-lab
kubectl get nodes
```

Очікуваний вивід:
```
NAME                       STATUS   ROLES           AGE   VERSION
argocd-lab-control-plane   Ready    control-plane   1m    v1.31.x
```

## 3. Встановлення ArgoCD

Встановлення ArgoCD однакове для всіх платформ, оскільки він розгортається в Kubernetes за допомогою kubectl.

### Встановити ArgoCD

```bash
# Створити простір імен argocd
kubectl create namespace argocd

# Встановити ArgoCD
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

# Дочекатися готовності всіх подів (це може зайняти кілька хвилин)
kubectl wait --for=condition=Ready pods --all -n argocd --timeout=300s
```

### Перевірка встановлення ArgoCD

```bash
kubectl get pods -n argocd
```

Очікуваний вивід (усі поди мають бути в стані Running):
```
NAME                                                READY   STATUS    RESTARTS   AGE
argocd-application-controller-0                     1/1     Running   0          2m
argocd-applicationset-controller-xxx                1/1     Running   0          2m
argocd-dex-server-xxx                               1/1     Running   0          2m
argocd-notifications-controller-xxx                 1/1     Running   0          2m
argocd-redis-xxx                                    1/1     Running   0          2m
argocd-repo-server-xxx                              1/1     Running   0          2m
argocd-server-xxx                                   1/1     Running   0          2m
```

### Доступ до UI ArgoCD

**Варіант 1: Port Forwarding (рекомендовано для локальної розробки)**

```bash
kubectl port-forward svc/argocd-server -n argocd 8080:443
```

Потім відкрийте https://localhost:8080 у вашому браузері.

**Варіант 2: Використання minikube service (якщо ви використовуєте minikube)**

```bash
minikube service argocd-server -n argocd
```

**Варіант 3: NodePort (для kind)**

```bash
kubectl patch svc argocd-server -n argocd -p '{"spec": {"type": "NodePort"}}'
```

### Отримання пароля адміністратора ArgoCD

```bash
# Отримати початковий пароль адміністратора
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
```

> **Примітка для Windows (PowerShell):**
> ```powershell
> kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | ForEach-Object { [System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String($_)) }
> ```

**Облікові дані для входу:**
- **Ім'я користувача:** `admin`
- **Пароль:** (вивід попередньої команди)

## 5. ArgoCD CLI (опціонально)

ArgoCD CLI надає доступ до операцій ArgoCD з командного рядка.

### macOS

**За допомогою Homebrew:**
```bash
brew install argocd
```

**За допомогою curl:**
```bash
# Intel Mac
curl -sSL -o argocd-darwin-amd64 https://github.com/argoproj/argo-cd/releases/latest/download/argocd-darwin-amd64
sudo install -m 555 argocd-darwin-amd64 /usr/local/bin/argocd

# Apple Silicon (M1/M2/M3)
curl -sSL -o argocd-darwin-arm64 https://github.com/argoproj/argo-cd/releases/latest/download/argocd-darwin-arm64
sudo install -m 555 argocd-darwin-arm64 /usr/local/bin/argocd
```

### Linux

**За допомогою curl:**
```bash
curl -sSL -o argocd-linux-amd64 https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
sudo install -m 555 argocd-linux-amd64 /usr/local/bin/argocd
rm argocd-linux-amd64
```

### Windows

**За допомогою Chocolatey:**
```powershell
choco install argocd-cli
```

**Завантаження вручну (PowerShell):**
```powershell
$version = (Invoke-RestMethod https://api.github.com/repos/argoproj/argo-cd/releases/latest).tag_name
$url = "https://github.com/argoproj/argo-cd/releases/download/" + $version + "/argocd-windows-amd64.exe"
Invoke-WebRequest -Uri $url -OutFile $env:USERPROFILE\argocd.exe
# Додайте до PATH або перемістіть у папку, що є в PATH
```

### Використання ArgoCD CLI (усі платформи)

```bash
# Увійти до ArgoCD (port-forward має бути запущений)
argocd login localhost:8080 --insecure

# Перевірити вхід
argocd account get-user-info

# Переглянути список додатків
argocd app list
```

## Контрольний список перевірки

Виконайте ці команди, щоб перевірити правильність встановлення всіх передумов:

```bash
# 1. kubectl
kubectl version --client
echo "---"

# 2. Кластер Kubernetes
kubectl get nodes
echo "---"

# 3. ArgoCD
kubectl get pods -n argocd
echo "---"

# 4. Git
git --version
echo "---"

# 5. ArgoCD CLI (опціонально)
argocd version --client 2>/dev/null || echo "ArgoCD CLI не встановлений (опціонально)"
```

**Очікувані результати:**
- kubectl показує версію клієнта
- Принаймні один вузол у стані Ready
- Усі поди ArgoCD у стані Running
- Відображається версія Git
- Версія ArgoCD CLI (якщо встановлений)

## Усунення неполадок

### kubectl: command not found

Переконайтеся, що kubectl є у вашому PATH:
```bash
# Перевірте, де встановлений kubectl
which kubectl    # macOS/Linux
where kubectl    # Windows
```

### minikube не запускається

1. Переконайтеся, що Docker запущений (якщо використовуєте драйвер Docker)
2. Спробуйте видалити та створити заново:
   ```bash
   minikube delete
   minikube start
   ```
3. Перевірте доступні драйвери:
   ```bash
   minikube start --help | grep driver
   ```

### Створення кластера kind не вдається

1. Переконайтеся, що Docker запущений
2. Перевірте, що Docker має достатньо виділених ресурсів
3. Спробуйте з детальним виводом:
   ```bash
   kind create cluster --name test -v 1
   ```

### Поди ArgoCD не запускаються

1. Перевірте стан подів:
   ```bash
   kubectl describe pods -n argocd
   ```
2. Перевірте події:
   ```bash
   kubectl get events -n argocd --sort-by='.lastTimestamp'
   ```
3. Переконайтеся, що кластер має достатньо ресурсів

### Немає доступу до UI ArgoCD

1. Перевірте, що port-forward запущений
2. Спробуйте інший порт:
   ```bash
   kubectl port-forward svc/argocd-server -n argocd 9090:443
   ```
3. Перевірте, чи не блокує порт файрвол

### Проблеми з декодуванням Base64 у Windows

Використовуйте PowerShell з правильним декодуванням:
```powershell
$encoded = kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}"
[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String($encoded))
```

## Скрипт швидкого старту

Для швидкого налаштування ви можете використовувати ці об'єднані команди:

### macOS (з Homebrew)

```bash
# Встановити всі інструменти
brew install kubectl minikube argocd git

# Запустити кластер та встановити ArgoCD
minikube start --cpus=4 --memory=8192
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
kubectl wait --for=condition=Ready pods --all -n argocd --timeout=300s

# Отримати пароль та запустити port-forward
echo "Пароль адміністратора ArgoCD:"
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
echo ""
kubectl port-forward svc/argocd-server -n argocd 8080:443
```

### Linux (Debian/Ubuntu)

```bash
# Встановити kubectl
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
sudo install kubectl /usr/local/bin/

# Встановити minikube
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube

# Встановити git
sudo apt-get update && sudo apt-get install -y git

# Запустити кластер та встановити ArgoCD
minikube start --cpus=4 --memory=8192
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
kubectl wait --for=condition=Ready pods --all -n argocd --timeout=300s

# Отримати пароль
echo "Пароль адміністратора ArgoCD:"
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
echo ""
```

### Windows (з Chocolatey)

```powershell
# Встановити всі інструменти (запустіть від імені Адміністратора)
choco install kubernetes-cli minikube argocd-cli git -y

# Перезапустіть PowerShell, потім:
minikube start --cpus=4 --memory=8192
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
kubectl wait --for=condition=Ready pods --all -n argocd --timeout=300s

# Отримати пароль
$encoded = kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}"
Write-Host "Пароль адміністратора ArgoCD:"
[System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String($encoded))
```
